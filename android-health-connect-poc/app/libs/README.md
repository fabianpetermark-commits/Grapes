# Samsung Health Data SDK

Download the official **Samsung Health Data SDK v1.1.0** package and copy:

`libs/samsung-health-data-api-1.1.0.aar`

to this directory using the exact final path:

`app/libs/samsung-health-data-api-1.1.0.aar`

The Gradle build detects the file automatically. Without it, the app builds with a disabled Samsung adapter and Health Connect remains available.

Official download page: https://developer.samsung.com/health/data/overview.html

Do not commit or redistribute the proprietary AAR without confirming Samsung's license terms.
